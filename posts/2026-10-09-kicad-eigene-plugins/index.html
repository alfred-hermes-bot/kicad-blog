KiCad ist von Haus aus ein mächtiges Werkzeug – aber eines der bestgehüteten Geheimnisse ist der Plugin and Content Manager (PCM). Damit erweiterst du KiCad um zusätzliche Werkzeuge, Bibliotheken, 3D-Modelle und Farbthemen – ganz ohne manuelles Kopieren von Dateien. In diesem Beitrag zeigen wir dir, wie du Plugins aus einer .zip-Datei installierst und wie du sie wieder loswirst.

Was du lernst

  • Was der Plugin and Content Manager (PCM) ist und welche Paketarten es gibt
  • Plugins aus einer .zip-Datei über Install from File installieren
  • Installierte Pakete aktualisieren und deinstallieren

Voraussetzungen

  • KiCad 10 installiert (siehe unseren Installationsguide)
  • Die .zip-Datei des Pakets (z. B. vom USB-Stick oder Schulserver)
  • Grundlegende Kenntnisse der KiCad-Benutzeroberfläche

Was ist der Plugin and Content Manager?

Der PCM ist KiCads zentrale Anlaufstelle für Erweiterungen. Er verwaltet vier Arten von Paketen:

Paketart Beispiele
Plugins Zusatzwerkzeuge im Schaltplan- und PCB-Editor, z. B. BOM-Exporte, DFM-Prüfungen, Bemaßungs-Helfer
Bibliotheken Symbol- und Footprint-Bibliotheken von Herstellern wie SparkFun oder Adafruit
3D-Modelle STEP-/WRL-Modelle für die 3D-Ansicht
Farbthemen Alternative Farbschemata für die Editoren

Der PCM kann auch direkt aus dem offiziellen Repository (https://plugins.kicad.org) installieren – das ist aber nicht das Thema dieses Beitrags. Hier geht es gezielt um die .zip-Datei.

Schritt 1: Den PCM öffnen

  1. Starte KiCad – der Projektmanager genügt.
  2. Gehe zu Tools → Plugin and Content Manager

Der PCM ist in drei Reiter unterteilt:

  • Browse – alle verfügbaren Pakete aus dem Repository
  • Installed – deine installierten Pakete
  • Updates – Pakete, für die eine neue Version verfügbar ist

Schritt 2: Plugin aus einer .zip-Datei installieren

  1. Hol dir die .zip-Datei des Pakets – vom Schulserver
  2. Klicke im PCM auf die Schaltfläche Install from File
  3. Wähle die .zip-Datei des Pakets aus und bestätige
  4. Der PCM liest die metadata.json, prüft die kompatible KiCad-Version und installiert das Paket

Wichtig bei Plugins: Action-Plugins werden beim Start von KiCad geladen. Nach der Installation starte KiCad einmal neu und öffne den Board Designer.

Jetzt stehen dir die Inhalte des Plugins zur Verfügung.

Plugin testen

In House Vorlage

  1. Starte KiCad neu
  2. Erstelle ein neues Projekt und überprüfe, ob die Vorlage für die in House Fertigung (File → New → Project)

Taucht der Eintrag auf, war die Installation erfolgreich.

In House Bauteile

Nachdem du ein Projekt angelegt hast, öffne den Schematic Editor und platziere ein Bauteil. In der Symbolauswahl sollte jetzt die Bibliothek für die in House Bauteile verfügbar sein.

Note

Für mehr übersichtlichkeit können die mit KiCAD installierten Bibliotheken in den Einstellungen unter Preferences → Manage Symbol Libraries und Preferences → Manage Footprint Libraries verwaltet werden. Dort können Bibliotheken aktiviert, deaktiviert oder priorisiert werden.
