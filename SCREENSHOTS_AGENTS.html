Channel protocol (how to drive KiCad)

From python/commands/gui_driver.py _send/_call: one JSON line per TCP connection to 127.0.0.1:8770; echo the session token from the token file on every request; read one JSON response line.

  • Requests: {"cmd": "tree", "frame": optional} → menus/toolbars inventory (items have name, id, enabled; destructive items prefixed “⚠”). {"cmd": "click", "name"|"id", "kind", "frame"} → activate menu/toolbar. {"cmd": "run_plugin", "name"} → Tools > External Plugins entry. {"cmd": "wait_for", "title", "timeout"} → poll for a top-level window. {"cmd": "screenshot", "path", "frame"} → capture frame rect to PNG, returns the path. {"cmd": "click_button", "title", "label"} and {"cmd": "scrape", "title"} → drive dialog buttons / read dialog grids (used by the DRC playbook; also the tools for the PCM dialog).
  • Response: {"ok": true, "result": ...} or {"ok": false, "error": ...}.
  • MCP-server-side equivalents (if the user’s client has this MCP connected): tools kicad_gui_tree, kicad_gui_click, kicad_gui_wait_for, kicad_gui_screenshot, kicad_run_action_plugin, kicad_run_drc.

Working client one-liner (verified, copy-paste into bash)

"/c/Program Files/KiCad/10.0/bin/python.exe" -c "
import json, socket
tok = open(r'C:\Users\leo\AppData\Roaming\kicad\gui_driver_8770.token').read().strip()
s = socket.create_connection(('127.0.0.1', 8770), 10)
s.sendall((json.dumps({'cmd': 'tree', 'token': tok}) + '\n').encode('utf-8'))
resp = s.makefile('r', encoding='utf-8').readline()
s.close()
print(json.dumps(json.loads(resp), ensure_ascii=False)[:600])
"
